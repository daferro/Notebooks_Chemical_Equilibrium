# Notebooks_Chemical_Equilibrium
Jupyter/Python notebooks for teaching gas-phase chemical equilibrium through an integrated thermodynamic, kinetic, and statistical-mechanical approach. Includes interactive simulations, equilibrium shifts, time-dependent kinetics, and links between molecular properties, partition functions, and macroscopic observables.
